Ghost Tag

VS Code Extension / 2026

Tools & Environment

Development

TypeScript / JavaScript

About

Ghost Tag（ゴーストタグ）は、精度と処理速度、構造解析の安定性を追求して開発したVS Code向けの双方向タグ自動同期拡張機能。スタックベースのペアリングアルゴリズムにより、ネストの深い複雑なHTML/XML構造においても開始タグと閉じタグの変更を正確かつリアルタイムに追跡します。

Features

開始タグと閉じタグの変更をリアルタイムに双方向同期します。スマートなマルチカーソル処理と衝突防止機構を備え、複数箇所の同時編集時にもテキスト崩れや意図しない書き換えを防ぎます。属性を持つタグや自己完結型タグ（<img />, <br /> など）の構造も正確に判定し、快適なコード編集環境を実現します。

Supported Languages

HTML / XML
React (JSX / TSX)
Vue / Svelte
PHP / Blade
