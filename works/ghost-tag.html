Ghost Tag：リアルタイム双方向タグ自動同期

Ghost Tag は、精度・速度・構造解析の安定性を追求して設計された VS Code 向けの高性能な双方向タグ自動更新拡張機能です。

主な特徴と機能

双方向リアルタイム同期 — 開始タグと閉じタグの変更をリアルタイムかつシームレスに同期します。
階層構造のコンテキスト認識 — スタックベースのペアリングアルゴリズムにより、深いネスト構造を正確に追跡します。
衝突防止・マルチカーソル対応 — スマートなマルチカーソル処理により、テキスト崩れや不正な書き換えを防ぎます。
属性・自己完結タグ対応 — 複雑な属性を持つタグや自己完結型タグ（<img />, <br /> など）を正しく認識します。

対応言語

・HTML / XML
・React (JSX / TSX)
・Vue / Svelte
・PHP / Blade

更新履歴 (Changelog)

v1.0.6 — 自己完結型タグのサポート修正。<img /> や <br /> などの要素がネストスタックを崩さないよう修正。正規表現の強化。
v1.0.5 — 複数属性を持つタグの対応、深層ネスト構造でのペアリング精度を改善。
v1.0.4 — 空タグ（<>）操作時の同期処理を改善。座標計算を手動Range計算に切り替え、位置精度を100%化。
v1.0.0 - v1.0.3 — 初版リリース。基本機能と双方向同期・ネスト解析を実装。
