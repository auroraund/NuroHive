About

A lightweight masonry layout built entirely with vanilla JavaScript and SCSS, without external library dependencies. It dynamically calculates element heights upon detecting image loads and handles card positioning responsive to viewport width.

Features

Designed without third-party dependencies for direct integration into web applications. Uses Promise.all to defer layout calculations until all images are fully loaded to prevent layout shifts, while handling column count updates and CSS transition animations on viewport resize.
