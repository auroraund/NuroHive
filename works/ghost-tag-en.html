Ghost Tag: Real-time Bi-directional Auto Rename Tag

Ghost Tag is a high-performance VS Code extension engineered for precision, speed, and structural stability when synchronizing HTML/XML tags.

Key Features

Bi-directional Real-time Sync — Seamlessly synchronizes opening and closing tag modifications in real-time.
Context Awareness — Accurately tracks deeply nested structures using a stack-based pairing algorithm.
Collision Prevention — Intelligent multi-cursor handling to prevent text corruption.
Attribute-Safe & Self-Closing Support — Correctly identifies tags even with complex attributes and self-closing elements (<img />, <br />).

Supported Languages

・HTML / XML
・React (JSX / TSX)
・Vue / Svelte
・PHP / Blade
