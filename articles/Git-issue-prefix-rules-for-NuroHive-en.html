Git commit prefix cheat sheet

Follow these standardized prefixes to keep your git history clean, readable, and structured.

Features and bug fixes

feat: — Adding a new feature or functionality.
fix: — Resolving a bug or unexpected behavior.
refactor: — Rewriting code to improve structure without changing behavior.
perf: — Improving performance, memory, or execution speed.

Documentation and chores

docs: — Updating documentation, READMEs, or article titles.
style: — Adjusting formatting, fixing typos, or tweaking UI spacing.
chore: — Updating dependencies, build tools, or config files.
