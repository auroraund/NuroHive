Git / 2026

よく使うGitのプレフィックスルール

コミット履歴を視認性よく綺麗に保つための、NuroHive運用におけるルール一覧。

機能追加とバグ修正

feat/— 新機能の追加
fix/— バグや不具合の修正
refactor/— 挙動を変えずにコードを綺麗に整理
perf/— 処理速度やパフォーマンスの改善

ドキュメントとメンテナンス

docs/— READMEやドキュメント類の更新
style/— コード整列、タイポ修正、CSSの余白調整など
chore/— パッケージ更新や設定ファイルの変更
